# 📌 Overview

This project presents a **Transformer-based Medical NLP System** designed to automatically predict multiple diseases from radiology reports using advanced Natural Language Processing techniques.

The model leverages transformer architectures to extract contextual clinical information from free-text radiology reports and perform **multi-label disease classification**.

---

# 🔬 Transformer Attention Mechanism

```math
Attention(Q,K,V)=softmax((QKᵀ)/√dₖ)V
```

This mechanism allows the model to understand contextual relationships between medical terms and clinical findings.

---

# 🧬 Multi-Label Classification

Unlike traditional classification systems, a radiology report may contain **multiple diseases simultaneously**.

This project uses:

- Sigmoid Activation
- Binary Cross Entropy Loss
- Multi-Label Prediction Pipeline
